## Phase 1：地基（#2 + #11）

**目标**：验证信源可信度，补上基本面数据缺口。

| # | 方向 | 输入 | 输出 | 工期 | 优先级 |
|---|------|------|------|------|--------|
| #2 | **准确率回溯** | analyzed_cleaned + prices | 每人胜率、超额收益、夏普 | 2 天 | 🔴 P0 |
| #11 | **基本面快照** | Polygon Financials API | PE/ROE/增速缓存 | 0.5 天 | 🟡 P1 |

**为什么先做 #2**：它是整个系统的信仰基石。如果 TJ 的准确率只有 45%，后面 11 个方向全没意义。做完 #2 你会知道：
- 他买的建议对了几次
- 他的超额收益是多少
- 哪个时间窗口（1个月/3个月/1年）他最稳定

**为什么同时做 #11**：基本面数据是 #7（角色代入）和 #13（持仓叠加）的前置依赖，早晚要拉。现在拉好，后面直接用。

**交付物**：
- `data/accuracy_report.json` — 每个分析师的完整准确率数据
- `data/fundamental_cache.json` — 被提及股票的 PE/ROE/增速快照
- Streamlit 面板加一栏："📊 准确率"

## Phase 2：信号引擎（#1 + #4）

**目标**：把"他说看多"变成可比较的数字。

| # | 方向 | 输入 | 输出 | 工期 | 优先级 |
|---|------|------|------|------|--------|
| #1 | **信号量化** | analyzed_cleaned + prices + #2 校准权重 | 0-100 信号分 | 2 天 | 🔴 P0 |
| #4 | **多信号联动** | #1 两人信号 | 联动共识分 | 0.5 天 | 🟡 P1 |

**为什么 #1 是 P0**：它是一切上层能力的底座。做完后每天能出一个"今日信号 TOP 5"——虽然简陋，但已经有实用价值了。

**关键决策**：stance/confidence 的权重用 Phase 1 的回溯数据来校准，不是拍脑袋设。

**交付物**：
- 每条 analyzed 推文追加 `signal_score` 字段
- 联动分数（当两人同时覆盖同一股票时）
- Streamlit 加一栏："📡 信号"

---

## Phase 3：分析智能（#7 + #8 + #9）

**目标**：从"看信号"升级到"理解人"。

| # | 方向 | 输入 | 输出 | 工期 | 优先级 |
|---|------|------|------|------|--------|
| #8 | **板块轮动检测** | analyzed_cleaned sectors | 热力图 + Sankey 图 | 1 天 | 🟡 P1 |
| #9 | **情绪时间线** | 单股 × 单人的 stance 时序 | 双轴 K 线+态度图 | 1 天 | 🟡 P1 |
| #7 | **角色代入选股** | 画像 + #11 基本面 + K 线 + LLM | "如果是他，会买什么" | 2 天 | 🟡 P1 |

**#8 和 #9 是 #7 的前序**——你需要先看清他往哪转、他怎么看具体股票，然后才能让 LLM 模拟他的决策。#8 和 #9 可以并行做。

**交付物**：
- #8：Streamlit 面板 — 板块轮动热力图
- #9：Streamlit 面板 — 选一只股票，看分析师对它的态度变化曲线
- #7：输入板块 → LLM 输出选股方案，附推理过程

---

## Phase 4：实时化（#3 + #10 + #5 + #12）

**目标**：从"手动查看"变成"自动通知"。

| # | 方向 | 输入 | 输出 | 工期 | 优先级 |
|---|------|------|------|------|--------|
| #3 | **实时触发** | 新推文 DB 轮询 | 自动 filter → analyze | 1.5 天 | 🟡 P1 |
| #10 | **异常检测** | 画像 baseline + 新推文 KL 散度 | 偏离预警 | 2 天 | 🟡 P1 |
| #5 | **预警系统** | 用户持仓 + #10 | 持仓股异常推送 | 0.5 天 | 🟢 P2 |
| #12 | **关联网络** | tweet 回复/引用关系 | 信源推荐图 | 1 天 | 🟢 P2 |

**#3 和 #10 并行做**；#5 是 #10 的子集（只需持仓股过滤）；#12 独立。

**关键设计决策**：#3 的实时触发要加日预算上限（默认 20 次 analyze/天），避免 API 费用失控。

**交付物**：
- Telegram Bot 推送（持仓股被提 + 态度变化）
- 异常检测日志
- 关联网络交互图（推荐新信源）

## Phase 5：个性化（#13 + #6）

**目标**：从"看他怎么做"变成"你该怎么做"。

| # | 方向 | 输入 | 输出 | 工期 | 优先级 |
|---|------|------|------|------|--------|
| #13 | **持仓叠加层** | 你的持仓 + #1 信号 + #7 角色代入 | 个性化建议 | 2 天 | 🟢 P2 |
| #6 | **完整控制台** | 前 12 个方向的全部输出 | 统一仪表盘 | 1.5 天 | 🟢 P2 |

**#13 是最危险的方向**——直接关联你的真实资金。设计上**强制保留人工确认环节**，不做自动执行。

**交付物**：
- 上传持仓 CSV → 每只股票附分析师视角建议
- 统一控制台：今日信号 TOP5 + 板块轮动 + 预警 + 网络图
